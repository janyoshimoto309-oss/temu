# Temu × 知了筛选

Chrome MV3 本地插件。和「知了数据」同时开，**只读页面**，按门槛把不合格商品卡变灰；半价数字是独立展示。

## 加载

见 `加载说明.txt`。选中本仓库根目录（含 `manifest.json`）。

## 模块

- **A** 规则筛选：两套数字门槛（套内并且、两套或）+ 共用不看；日/周/月销、上架（超过近 N 用 `>`，单位只有月）、评分、评论、Temu 已售。不看含套装件数 > N、现价 ≤ N（空=不启用）。详情页只筛下方推荐，主商品不筛
- **B** AI 分类：默认关，BYOK Gemini，只补规则漏网
- **C** 自动点开：点「开始」才跑，只有开始/停止。只点未变灰的卡；本模块门槛和不看只决定点谁，不变灰
- **D** 半价数字：现价÷2，只标数字，不参与变灰。面板可在黑紫 / 白蓝两套壳之间切换，不影响筛选

空字段或「-」跳过该条门槛。知了蓝框封闭 Shadow 能读不能写。
